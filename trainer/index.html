    Trainer

    Configuration Object

    Training setup is configured using a XZTrainerConfig dataclass object.

    Below is a list of properties you can configure.

    xztrainer.model.XZTrainerConfig dataclass

    A configuration for XZTrainer training setup

    collate_fn: t.Callable[[list[object]], t.Any] = default_collate class-attribute instance-attribute

    A function used to collate multiple dataset items into a single batch.

    dataloader_num_workers: int = multiprocessing.cpu_count() class-attribute instance-attribute

    Number of worker processes used for data loaders.

    dataloader_persistent_workers: bool = True class-attribute instance-attribute

    Boolean value indicating whether to keep workers alive after each epoch.

    dataloader_pin_memory: bool = True class-attribute instance-attribute

    Boolean value indicating whether to pin memory for data loaders.

    dataloader_shuffle_train_dataset: bool = True class-attribute instance-attribute

    Boolean value indicating whether to shuffle a training dataset within a dataloader.

    epochs: int instance-attribute

    Number of epochs to train for.

    eval_steps: int = 0 class-attribute instance-attribute

    Controls frequency of running a model on evaluation set.

    Can be either:

    • -1 - to disable evaluation

    • 0 - to evaluate only after an epoch finishes

    • Any positive value - to evaluate at each Nth training step

    experiment_name: str instance-attribute

    Name of current experiment. Used for logging and checkpoint saving

    gradient_clipping: float = 1.0 class-attribute instance-attribute

    Max gradient norm used for gradient clipping. Can be set to 0 to disable gradient clipping.

    log_steps: int = 100 class-attribute instance-attribute

    Controls frequency of logging model metrics.

    Can be either:

    • -1 - to disable logging

    • 0 - to log only after an epoch finishes

    • Any positive value - to log at each Nth training step

    logging_level: t.Union[int, None] = logging.INFO class-attribute instance-attribute

    Logging level that xztrainer initializes Python loggers with. Set to None to make xztrainer not do anything with Python loggers.

    minibatch_size: int instance-attribute

    Minibatch size used for training. In case of a multi-gpu or gradient accumulated train setup, it is a physical batch size for a single GPU.

    minibatch_size_eval: int instance-attribute

    Minibatch size used for evaluation. In case of a multi-gpu or gradient accumulated train setup, it is a physical batch size for a single GPU.

    optimizer: t.Callable[[nn.Module], Optimizer] instance-attribute

    A callable that creates an Optimizer object from a Module object. Module object can be used to pass its parameters to Optimizer constructor, for example.

    Examples:

    >>> optimizer=lambda module: AdamW(module.parameters(), lr=1e-3, weight_decay=1e-4)

    save_keep_n: int = 3 class-attribute instance-attribute

    Number of saves to keep while training. After a new save finished, all the other saves will be deleted except for save_keep_n last ones. Set to -1 to disable save removal.

    save_steps: int = 100 class-attribute instance-attribute

    Controls frequency of saving a model and trainer state.

    Can be either:

    • -1 - to disable saving

    • 0 - to save only after an epoch finishes

    • Any positive value - to save at each Nth training step

    scheduler: t.Callable[[Optimizer, int], LRSchedulerProtocol] instance-attribute

    A callable that creates a Learning Rate Scheduler object from an Optimizer and total number of training steps.

    Examples:

    >>> scheduler=lambda optim, total_steps: transformers.get_linear_schedule_with_warmup(optim, int(0.1 * total_steps), total_steps)

    skip_nan_loss: bool = True class-attribute instance-attribute

    Boolean value indicating whether to skip update when a NaN loss value occurs.

    tracker_config: dict[str, t.Any] = field(default_factory=dict) class-attribute instance-attribute

    Arbitrary hyperparameters logged to experiment tracker.

    tracker_init_kwargs: dict[str, t.Any] = field(default_factory=dict) class-attribute instance-attribute

    Arbitrary keyword arguments used for Accelerate experiment tracker. Directly passed to accelerator.init_trackers(...). See Accelerate docs

    train(train_data, eval_data)

    This function:

    1. Prepares all the objects used for further training, such as optimizer, dataloaders, metrics, learning rate scheduler, logger.
    2. Wraps these objects using accelerator.prepare(...)
    3. If a training checkpoint exists - loads it and initializes all the previously prepared objects from it.
    4. Prints out total parameter count used for training
    5. Trains for N epochs, where N specified in trainer config
    6. While training, the trainer can save its state, run evaluation and log metrics, - it is specified in trainer config.

    Parameters:

    Name Type Description Default
    train_data Dataset

    Dataset used for training

    		 required
    eval_data Optional[Dataset]

    Dataset used for evaluation. Can be None to disable evaluation.

    		 required
