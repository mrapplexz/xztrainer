    cut_model_outputs(context, model_outputs, remainder)

    Function used to cut out model_outputs based on a remainder value.

    Since accelerate repeats some last samples in both validation and training datasets (let's call these samples "padded samples") to ensure batches are split across GPUs evenly in distributed setups, you may want to cut out these padded samples before metric calculation.

    Default implementation just doesn't do anything because it does not know model output artifacts structure.

    If you doesn't implement this function, you may see a slight difference between calculated metrics for a distributed and non-distributed setups.

    Examples:

    >>> return {'predictions': model_outputs['predictions'][:-remainder]}

    Parameters:

    Name Type Description Default
    context BaseContext

    Current train/evaluation context

    		 required
    model_outputs ModelOutputsType

    Model output artifacts

    		 required
    remainder int

    Number of last samples that are padded samples and need to be cut out.

    		 required
